# Point-in-time 数据与事件顺序规范（Phase A）

## 1. 为什么独立成文

回测是否可信，首先取决于历史决策是否只使用当时能掌握的信息。报表期、公布时刻、下载时刻不等价；复权价格不能直接拿来当订单成交价；今天存在的股票集合也不是历史所有股票的集合。

## 2. 时间语义

| 字段 | 意义 | 示例 |
| --- | --- | --- |
| `event_at` | 市场/业务事件发生时刻 | 交易所 T 日收盘 |
| `published_at` | 原始发布方公开信息时刻 | 公司披露报告 |
| `available_at` | 对本策略合理可见的最早时刻 | 交易所数据/供应商可用 |
| `ingested_at` | nano-quant 系统实际取得该数据的时刻 | 历史回填或直播接入 |
| `as_of` | 决策时刻与可见信息上界 | T 日收盘后 |
| `effective_at` | 公司行为生效时刻（如适用） | 拆股执行日 |

历史研究中的“公开信息视角”要求 `available_at <= as_of`；模拟实际部署的运营回放还要求当时 `ingested_at <= as_of`，否则就相当于假设已经摄取尚未进入系统的资料。离线历史回填不应冒充历史系统实际持有记录。

重要：只有报告期没有披露时间的财务条目不能用作严格 PIT 研究的事实证据；需要来源映射或保守滞后且明确局限的实验假设。

## 3. 日频事件约定

```text
T trading session CLOSE
  -> CLOSE bar becomes AVAILABLE
  -> compute factor and forecast with as_of=T_after_close
  -> strategy -> portfolio -> pre-trade risk approval
T+1 trading session OPEN
  -> simulate fills at raw open ± slippage and fee
T+1 trading session CLOSE
  -> mark-to-market -> audit ledger -> metrics
```

任何研究或执行组件都不得将 T+1 开盘/收盘价用于 T 日收盘后的交易信号。单交易日发生停牌/无有效开盘价时，订单不能虚构成交；必须依规则拒单、取消或保留（选择要固定在配置中）。

## 4. 股票池、公司行为及价格口径

- 股票池使用日期有效的证券主数据，纳入退市与历史成分变化；禁止默认仅使用当前仍存续证券。
- 研究因子可使用明确复权/含息口径数据；成交引擎使用当日**未复权可交易价格**。
- 拆股、分红、换股、停牌和退市应作为独立公司行为/状态事件处理；不支持时显式失败。v1.0 标准合成数据设置无公司行为，但文档不能暗示支持了真实公司行为。
- 时区与交易日历决定何谓“下一个交易日”，不能简单加 24 小时或把周末当成交易日。
- 货币、最小报价单位、交易单位和小数精度都在 instrument metadata 与配置中声明。
- 历史回测中的调整价格、原始价格、供应商订正版本要分别保存，不能无审计地覆盖。

## 5. 数据质量断言

数据适配器及快照读取至少检查：
1. (instrument_id, session_date, source_version) 唯一性。
2. OHLC 一致性、价格/成交量合法区间、时区齐全。
3. 按 instrument+时间单调排序，交易日历一致。
4. `available_at <= as_of`；实际运营重放按规定加摄取时间检查。
5. 预热窗口满足需求；否则返回“不可计算”并记录原因。
6. 原始数据来源和版本可追溯；无授权数据不进入发布示例。

## 6. 独立时序反事实测试

- **Future perturbation**：固定 T 日决策，更改 T+1 及之后的数据。T 日信号、目标权重与批准结果必须逐字节或在预定浮点容差内不变。
- **Disclosure shift**：将一条财报的 `available_at` 改为 T 之后；T 日研究必须不再读取该条财报。
- **Next-open**：同一 T 的收盘信号对应订单，最早成交时间不早于下一有效交易日开盘。
- **Delisting fixture**：在历史股票池中包含后来退市资产，重建该日期的股票池不应自动删除该资产。
- **Corporate action sentinel**：出现 v1.0 不支持的拆股/分红时必须显式中止或拒绝该条用例，不能悄悄改变账本。

这些均为后续需实现的测试设计，Phase A 不应宣称它们已经运行。
