## 2. v1.0 Golden Ledger A（独立手算）

规定：
- 初始 USD 现金 = **1000.00**，无持仓。
- T 日收盘后生成买入 10 股的订单，并通过风险审批。
- T+1 日原始开盘价 = **10.00**，买单不利方向滑点 **0.10%**，每笔固定手续费 **1.00 USD**。
- 完全成交，无税费或公司行为；T+1 收盘价 = **11.00**。
- 以 Decimal 计算金额；USD 按 cents 做明确的量化规则。

预期：

```text
fill_price       = 10.00 * (1 + 0.001) = 10.01 USD/share
gross_purchase   = 10 shares * 10.01     = 100.10 USD
fee              = 1.00 USD
cash_after_fill  = 1000.00 - 100.10 - 1.00 = 898.90 USD
position         = 10 shares
market_value     = 10 * 11.00 = 110.00 USD
NAV_at_T+1_close = 898.90 + 110.00 = 1008.90 USD
absolute_PnL     = 8.90 USD
simple_return    = 8.90 / 1000 = 0.0089 = 0.89%
```

这是账本测试，不是预测模型或策略成功证明。现金、股数、费用精确匹配到分；浮点收益计算使用预先固定的绝对容差，如 `1e-12`。

## 4. v1.0 研究验证要求

- 模型训练/参数选择只使用当时合规的历史窗口；最终留出数据不参与研究选择。
- 结果包含 cash/no-trade 基线、简单策略基线、毛/净收益与成本敏感性。
- 合成数据仅用于验证确定性和数学/数据流程，不具有现实资产定价或 Alpha 外推意义。
- 如使用真实历史数据，应额外处理历史股票池、公告时间、公司行为、退市和可交易性；不满足时必须披露缺失条件，而不是发布无条件结论。
