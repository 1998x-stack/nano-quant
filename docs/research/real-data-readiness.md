# 真实一手数据准入门禁（目前未执行）

Phase D 的披露与退市记录均为**虚构测试证据**。真实实证研究前须落实：

1. **数据来源与授权**：交易所/获授权行情供应商、上市公司或监管机关的原始申报、发布机构经济数据及历史修订版本。保存供应商条款与分发范围；公开可见不等于可以任意复制。
2. **原文证据**：保存未改写的原始文档与 SHA256、来源 URL/标识、获取时间、数据模式和数据版本。衍生文件与原始文件分离。
3. **历史可得性**：独立记录 event_at、published_at、available_at、ingested_at，不能用现在的最终修订值替代历史公开值。
4. **证券完整性**：稳定 instrument_id、历史上市/退市记录、交易所真实日历、证券公告已知时间、停牌和缺失数据，不能仅用今日存续股票回测。
5. **价格与公司行为**：复权研究价与真实未复权成交价分离；分红、拆股、退市事件正确记账，暂不支持则中止而非偷偷跳过。
6. **独立统计证据**：预登记样本/因子定义、冻结最终测试集、记录研究尝试、不同年份的时间序列验证、合理交易成本、流动性容量、负向对照及不确定性。
7. **接受条件**：每个真实 provider 经许可核实、原始数据交叉抽样与 PIT 反事实验证后才可用于展示历史绩效；结果附数据版本/代码 commit/环境配置。

可能的原始数据入口包括 SEC EDGAR、FRED/ALFRED 与交易所发行人公告；具体接口、授权、覆盖情况尚未调查完成，也**未接入 nano-quant**。

**实际阻塞**：需要先选定研究市场、数据供应商/许可、真实交易日历与公司行为策略；当前不得宣布真实 Alpha 研究完成。
